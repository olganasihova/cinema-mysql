# База данных кинотеатра — MySQL

Учебный проект по разработке реляционной базы данных кинотеатра.

## Статус

Проект в разработке. Содержит небольшой набор тестовых данных.

## Содержание

- 15 связанных таблиц.
- 16 хранимых функций.
- 5 триггеров.
- Процедура refund_ticket для учебного возврата платежа и корректировки бонусов.
- Транзакция с COMMIT и обработчиком ошибок с ROLLBACK в процедуре возврата.

## Инструменты

MySQL 8.0, MySQL Workbench.

## Файл проекта

`cinemaaa.sql` — структура базы, данные, функции, триггеры и процедура.

## Запуск

Создать пустую базу в MySQL Workbench. Через Server → Data Import выбрать cinemaaa.sql и созданную базу в Default Target Schema, затем запустить импорт.
