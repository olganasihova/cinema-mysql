\# База данных кинотеатра - MySQL



Учебный проект по разработке реляционной базы данных кинотеатра.



\## Статус

Проект в разработке. Содержит небольшой набор тестовых данных.



\## Содержание

\- 15 связанных таблиц: клиенты, фильмы, залы, места, сеансы, билеты, платежи, отзывы и заказы еды.

\- 16 хранимых функций, включая добавление записей и расчёт стоимости билета.

\- 5 триггеров для обработки изменений данных.

\- Процедура refund\_ticket для учебного возврата платежа с корректировкой бонусов.

\- Транзакция с COMMIT и обработчиком ошибок с ROLLBACK в процедуре возврата.



\## Инструменты

MySQL 8.0, MySQL Workbench.



\## Файл

cinemaaa.sql - экспорт структуры базы, данных, функций, триггеров и процедуры.



\## Запуск

Создать пустую базу в MySQL Workbench и импортировать cinemaaa.sql через Server → Data Import, выбрав созданную базу в Default Target Schema.
